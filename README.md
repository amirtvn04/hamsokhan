# 🗣️ UniGap

> A student discussion platform for sharing knowledge, experiences, and answering academic questions.

[![React](https://img.shields.io/badge/React-19+-61DAFB.svg)](https://reactjs.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 📖 About the Project

UniGap is an online forum for students that helps them ask academic questions, share university experiences, discuss career paths, and leverage collective knowledge from the student community.

## ✨ Features

- 🧩 Forum system with topic categorization
- 📝 Create and manage discussion topics
- 💬 Reply system with real-time updates
- 🔐 User authentication and profile management
- 📡 Live chat between users
- 👤 User profile and activity history

## 🛠️ Technologies

**Frontend:**
- React
- React Router
- Tailwind CSS

**Backend:**
- Supabase (Auth, Database, Realtime)
- PostgreSQL
- Row Level Security

## 📂 Project Structure

```
src/
├── app/            # Main app configuration and Router
├── layouts/        # Page layouts
├── pages/          # Main pages
├── components/     # Reusable components
├── features/       # Modular logic (auth, topics, posts)
├── context/        # Contexts (Auth, Theme)
└── lib/            # Supabase connection
```
